Rowdy Code schnürte seinen Revolvergürtel enger. Schwer baumelte das prall gefüllte Holster an seiner Hüfte. Rowdy Code kaute wie in Zeitlupe auf seinem Priem Tabak und schob ihn langsam mit der Zunge in der Backe hin und her, her und hin. Rowdy Code wusste, wie er seine Gegner verrückt machen konnte. Statt auf seine schnelle Hand starrte jeder nur noch auf sein mahlendes Gebiss. Rowdy Code blinzelte nicht. Er zählte die Sekunden, wie lang der andere es aushielt. Keiner kam über dreißig Sekunden hinaus. Rowdy Code schob den Priem nach links, nach rechts, nach hinten … Rowdy Code verschluckte sich am Kautabak und hustete los, als Billy the Kid seinen Colt zog und ihm eine seiner blauen Bohnen genau zwischen die Augen feuerte. Das war das Ende von Rowdy Code, im Westen nur bekannt als „der Kauboy“.
